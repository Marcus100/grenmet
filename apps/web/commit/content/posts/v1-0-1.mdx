Version 1.0.1 followed v1.0.0 two days later and is mostly about what the public
sees on the weather site, plus the tool staff use to write for it.

### Weather site

- **Homepage:** a new hero with a card, tabs and panels.
- **Units:** a metric and imperial switch.
- **Plan your week:** a 16-block impact meter for the days ahead.
- **From the Desk:** posts with a picture and the author's name.

### Content tool

- A GMS Content menu, related links with a main link card, newsletter and social
  ticks, preview links and a publication log.

### API

- A daily climate newsletter, off by default.
- A social posting backend that only does a dry run.

### Elections and security

- A content refresh for the Elections site.
- A 14-day exception for `graphql-scalars` in the CMS migration image, recorded so
  it expires and is upgraded.
