# Barrels Grenada company hub

- Independent static site for `barrels.gd` on Cloudflare Pages (project `barrels`, production branch `main`); `www` redirects to the apex. Existing application subdomains remain independent.
- Pages: `index.html` (home, services overview, products, client examples, newsletter), `services/` (twelve services), `products/` (live and coming-soon products), `contact/`, `subscribe/status/` (confirm and unsubscribe landing, noindex). `build.mjs` writes `sitemap.xml` from the canonical links of indexable pages (no noindex) and `robots.txt` points to it. Shared header, footer and privacy card are `partials/*.html`, included at build time by `build.mjs` through `<!-- @include name -->`. Edit pages and partials, never `dist/`.
- Plain HTML/CSS with an optional consent-controlled analytics module and one shared `forms.mjs`; no framework; the only third-party script is Cloudflare Turnstile, loaded by `forms.mjs` when a site key is configured. Build with `node apps/web/barrels/build.mjs` from the repository root; it emits the shared analytics policy and Google transport as browser JavaScript.
- Forms are progressive enhancement. `forms.mjs` posts JSON to FastAPI (`https://api.barrels.gd`, or `http://localhost:8000` locally): contact to the per-site route `POST /api/v1/contact/public/barrels/messages` (the site is in the path; do not use the deprecated `POST /api/v1/contact/messages`), newsletter to `POST /api/v1/subscriptions` with `list_key: "barrels"`. Turnstile: `build.mjs` writes `dist/turnstile-config.mjs` from its first argument (`vercel.json` buildCommand passes the Vercel project variable `NEXT_PUBLIC_TURNSTILE_SITE_KEY`; empty: no widget, no token); `forms.mjs` then loads Cloudflare's script on form pages and sends `turnstile_token`. The CSP allows `https://challenges.cloudflare.com` in `script-src`, `frame-src` and `connect-src`. The CSP `connect-src` must keep the API origin, and production `BACKEND_CORS_ORIGINS` must list `https://barrels.gd` and `https://www.barrels.gd`. Never submit natively; the URL would carry the address.
- Copy in `services/` and `index.html` is draft, marked in comments; the owner edits it. Do not claim certifications, partnerships or clients that are not documented.
- Reuse the shared UI token declarations; never import GMS branding. Design: `docs/design/barrels.md`.
- Hosting (`docs/operations/vercel-exit-plan.md`): `build.mjs` writes `dist/_headers` from `vercel.json`'s headers, so `vercel.json` is still the one place to change the CSP. The `www` to apex redirect is a Cloudflare redirect rule, not a file.
- Verify with `node --test apps/web/barrels/site.test.mjs`. Output `dist/` is generated and ignored.
