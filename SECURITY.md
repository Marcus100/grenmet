# Security policy

Barrels Grenada builds and maintains the software in this repository, including
services used by the Grenada Airports Authority and the Grenada Meteorological
Service. Weather warnings are a public-safety function, so we take reports seriously.

## Reporting a vulnerability

Please report privately. Do not open a public issue or pull request for a security
problem.

1. Open the repository's **Security** tab and choose **Report a vulnerability**
   ([direct link](https://github.com/Marcus100/grenmet/security/advisories/new)).
2. Describe what you found, where, and how to reproduce it. Include affected URLs or
   file paths and the impact you expect.

Reports go to the Barrels Grenada engineering team. We review them, tell you what we
decide, and credit you if you wish once the fix is released.

## Please

- Test only against your own accounts and data.
- Stop and report if you reach personal data, credentials or another person's account;
  do not copy or keep it.
- Do not run denial-of-service tests, social engineering, or physical attacks.
- Give us reasonable time to fix a problem before sharing details publicly.

## Scope

The services and code in this repository. Reports about third-party platforms we use
(GitHub, DigitalOcean, Stripe and similar) should go to those providers.

## Supported versions

Only the latest published release and the `main` branch receive security fixes.
